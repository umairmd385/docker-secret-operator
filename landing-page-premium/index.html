How it works

Four steps from secret store to running container.

1

Store secrets

Add your secrets to AWS Secrets Manager, Azure Key Vault, or another supported provider.

2

DSO fetches

The DSO agent polls the provider and retrieves secret values over a secure connection.

3

DSO injects

Secrets are pushed into running containers as env vars or via /run/secrets/ file mounts.

4

Auto-updated

When the upstream value changes, containers receive the new value automatically. No restart needed.

Works with the secret stores you already use.

DSO uses a Go plugin architecture. Add any provider by dropping in a binary.

AWS Secrets Manager Azure Key Vault HashiCorp Vault Huawei CSMS Local File Environment

More providers coming. Plugin architecture makes adding new ones straightforward.

Example usage

Two files. That's all you need.

/etc/dso/dso.yaml 
# Provider configuration
provider: aws

config:
  region: us-east-1

agent:
  watch:
    polling_interval: 2m

secrets:
  - name: my-app-secret
    inject: env
    mappings:
      DB_PASSWORD: DATABASE_PASS
      DB_USER:     DATABASE_USER
docker-compose.yaml 
services:
  app:
    image: my-app:latest
    environment:
      - DB_PASSWORD_FILE=/run/secrets/DB_PASSWORD
      - DB_USER_FILE=/run/secrets/DB_USER

  db:
    image: postgres:16
    environment:
      - POSTGRES_PASSWORD_FILE=/run/secrets/DB_PASSWORD
$ dso compose up -d # DSO reads dso.yaml → fetches from AWS → injects into containers → starts stack

Getting started

Install DSO, configure your provider, and deploy in under 2 minutes.

1

Install DSO

bash 
curl -fsSL https://raw.githubusercontent.com/umairmd385/docker-secret-operator/main/install.sh | sudo bash
2

Configure provider credentials

Export your provider credentials to the host environment — e.g. AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY for AWS, or AZURE_CLIENT_ID for Azure.

3

Create /etc/dso/dso.yaml

dso.yaml 
provider: aws
config:
  region: us-east-1
secrets:
  - name: my-app-secret
    inject: env
    mappings:
      DB_PASSWORD: DATABASE_PASS
4

Start and deploy

bash 
# Start the DSO agent
sudo systemctl start dso-agent

# Deploy your stack (transparent wrapper around docker compose)
dso compose up -d
