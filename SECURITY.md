# Security Policy

## Supported Versions

At this time, only the latest version of DSO is officially supported for security updates. 

| Version | Supported          |
| ------- | ------------------ |
| > v2.0.0 | :white_check_mark: |
| < v2.0.0 | :x:                |

## Reporting a Vulnerability

We take security seriously and appreciate your feedback and contributions. If you believe you have found a security vulnerability in DSO, please report it as follows:

1. **Email us**: Send an email to `umairmd385@gmail.com` with the subject "SECURITY: <A brief description of the vulnerability>".
2. **Include details**: Provide a description of the vulnerability, steps to reproduce it, and any potential impact.
3. **Wait for a response**: We will acknowledge receipt of your report and provide an estimated timeline for a fix within 48 hours.
4. **Coordinate disclosure**: We ask that you do not disclose the vulnerability publicly until we have had a chance to fix it and release a security update.

## Our Commitment

We are committed to:

* Providing timely fixes for security vulnerabilities.
* Working with researchers and the community to identify and address security issues.
* Keeping our dependency versions up to date to minimize security risks.

Thank you for your help in keeping DSO secure!
